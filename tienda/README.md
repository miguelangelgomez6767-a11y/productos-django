# Sistema de Productos

Aplicación web desarrollada con Django para registrar y listar productos.

## Descripción

Este proyecto permite registrar productos de una tienda y consultar los productos almacenados en una base de datos SQLite.

Cada producto contiene:

- Nombre
- Categoría
- Precio
- Cantidad disponible

## Tecnologías

- Python
- Django
- SQLite
- HTML
- CSS
- Git
- GitHub

## Funcionalidades

- Registrar productos.
- Guardar productos en la base de datos.
- Listar productos registrados.
- Mostrar un mensaje cuando no existen productos.
- Navegar entre el formulario y el listado.
